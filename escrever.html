Escrever uma publicação nova

O jeito mais simples de publicar agora é pelo painel em /admin — é só entrar com seu login, escrever e clicar em publicar, sem mexer em nenhum arquivo. Esta página aqui é um caminho alternativo, manual, para quando você quiser escrever sem depender do painel: no final, ela gera um código pronto que você mesma cola no arquivo data/posts/ do repositório, do jeito explicado no passo a passo ao lado. Tudo o que você digita fica salvo automaticamente neste navegador enquanto trabalha.

Coloque suas imagens dentro de assets/images/posts/ no repositório e escreva o caminho aqui, ou cole um link direto de imagem.

Meta de escrita

Usada no "Diário de escrita" da Home.

1. Código do post

A primeira linha diz o nome do arquivo a criar. O resto é o conteúdo dele.

O código do post aparece aqui depois de clicar em "Gerar código do post".

2. Ritmo de publicação (opcional)

Só use isto se quiser trocar entre quinzenal e mensal — a data da última publicação é sempre automática.

3. Publicar no GitHub

  1. Abra o repositório no site do GitHub, pasta data/posts/.
  2. Clique em "Add file → Create new file".
  3. Dê ao arquivo o nome indicado na primeira linha do código copiado.
  4. Cole o restante do código (sem essa primeira linha de comentário) no corpo do arquivo.
  5. Clique em "Commit changes" para publicar.
  6. O site recompila sozinho e mostra a novidade em 1-2 minutos.
